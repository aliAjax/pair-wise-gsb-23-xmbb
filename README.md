# hxwl-09 半导体洁净室巡检

过滤器压差趋势监测与更换工单闭环看板。

## 技术栈

React + Vite + TypeScript + CSS（数据持久化于浏览器 localStorage）

## 本地运行

```bash
npm install
npm run dev      # 开发，端口 5109
npm test         # 领域不变式用例（纯函数，Node 直跑）
npm run typecheck
npm run build
```

## 业务闭环

1. **巡检登记**：房间/过滤器编号、初阻力（实测压差 Pa）、累计运行时长、设备状态。
2. **自动建单**：读数超过该房间区域上限，或最近 3 次读数严格连续上升时，系统生成「待派工」工单；同一过滤器存在未关闭工单时不重复建单（可由厂务工程师/班组长手工建单）。
3. **派工 → 锁定读数**：派工后以最近一次巡检为基准锁定读数与运行时长；锁定期间该过滤器不接受新巡检登记。
4. **备件更换**：必须选用有效期内、规格匹配且有余量的批次；完成更换时释放旧批次占用、绑定新批次，工单进入「待复测」。
5. **复测关闭**：更换后新读数必须较锁定值下降且不高于区域上限才允许关闭；未下降则拦截，工单保持「待复测」。
6. **补录留痕**：补录只允许带原因追加，旧值以 Revision 保留；已被工单锁定的基准读数永久不可修改。
7. **刷新一致**：状态写入 localStorage，刷新后趋势曲线、工单状态与批次占用关系保持一致。

## 角色

- 巡检员：登记巡检读数（触发自动建单）。
- 厂务工程师 / 班组长：派工、锁定、选批次更换、复测关闭、取消工单、补录修正。

## 代码结构

- `src/types.ts` 领域模型
- `src/domain.ts` 纯函数业务规则与不变式（无 React 依赖，可直接测试）
- `src/seed.ts` 演示数据（含连续上升、超限、更换中、已关闭、过期批次等场景）
- `src/store.tsx` localStorage 持久化与动作封装
- `src/components/` 巡检登记、压差趋势、工单闭环、批次台账、巡检台账
